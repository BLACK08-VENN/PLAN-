# Little Wins — ICEA LION

A mobile-friendly lobby platform game with four planning journeys, collectibles, and short discovery signs.

Open `index.html` locally or deploy the repository root as a static site on Vercel. The logo PNG belongs beside the HTML file.

The first-premium discount amount, eligible policies, and redemption terms must be confirmed by ICEA LION before public launch. The game does not collect customer data.
